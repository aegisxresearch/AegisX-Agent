# 🧠 MEMORY — AegisX Agent

Reflexion log for failures that were diagnosed and healed in this repo. Each
entry states what broke, why, and the rule that prevents it from coming back.
Read this before changing the modules it names.

### 🧠 Learned Invariants & Failure Post-Mortems

- **[26-10-22 · cli/main.py]**: `aegisx --persona pentester` ditolak dengan "No such option" padahal README menjanjikannya, dan nama persona yang salah ketik diam-diam menjalankan doktrin default. → **Root Cause**: flag `--persona` hanya dipasang di command `chat`/`run`, sedangkan callback root yang memanggil `chat` tidak meneruskannya; `PersonaLoader.get` mengembalikan prompt default untuk nama tak dikenal tanpa error. → **Invariant Rule**: setiap flag yang muncul di dokumentasi wajib punya test yang meng-invoke entry point-nya (bukan hanya `--help`), dan nama yang tidak dikenal harus gagal dengan daftar pilihan yang sah, bukan fallback diam.

- **[26-10-22 · cyber/checks/authz.py]**: Setiap scan default mengirim `PUT` dan `DELETE` ke root target, padahal README menjanjikan hanya GET/HEAD/POST. → **Root Cause**: `HTTPMethodCheck` “menguji” apakah sebuah write method aktif dengan cara mengirimkannya, dan `ScopePolicy.check()` menerima argumen `method` lalu tidak pernah memakainya — jadi tidak ada lapisan yang bisa menolak. → **Invariant Rule**: write verb tidak pernah diuji dengan menuliskannya; deteksi dari header `Allow` dan laporkan sebagai probable, bukan confirmed. Setiap parameter yang menyatakan batas keamanan harus benar-benar dipakai dan punya test yang membuktikan request-nya tidak pernah sampai ke jaringan.
- **[26-10-22 · cli/commands/cyber.py]**: `cyber scan --json > findings.json` menghasilkan file yang tidak bisa di-parse, sehingga alur `cyber report` gagal. → **Root Cause**: callback progress scanner menulis ke console stdout yang sama dengan dokumen JSON; stdout tidak pernah dipisahkan dari narasi. → **Invariant Rule**: stream hasil (stdout) dan stream narasi (stderr) adalah dua kontrak berbeda; perintah dengan output mesin harus diuji dengan benar-benar mem-parse stdout, bukan dengan memeriksa exit code.

- **[26-10-22 · cyber/recon.py]**: Crawl berhenti setelah halaman pertama; `Prober` menerima URL tanpa skema. → **Root Cause**: `Crawler._enqueue` mengembalikan `bool`, sedangkan `crawl()` mengantre `href` asli dari halaman (`/about`) alih-alih URL absolut hasil `urljoin`, sehingga `ScopeGuard` menolaknya sebagai malformed. → **Invariant Rule**: fungsi yang memutuskan "boleh diikuti" harus mengembalikan URL yang siap di-request (absolut, sudah dinormalisasi), bukan boolean yang memaksa pemanggil menebak.
- **[26-10-22 · cyber/recon.py]**: Semua versi teknologi kosong; advisory berbasis versi tidak pernah cocok. → **Root Cause**: `FingerprintRule.version_group` diketik `str` dan diisi `"1"`, lalu dipakai di `match.group("1")` — itu nama grup, bukan indeks; `IndexError` ditelan `except`, jadi kegagalan tidak terlihat. → **Invariant Rule**: indeks grup regex bertipe `int`; `except` yang menelan kesalahan pemrograman pada jalur data harus dihapus atau diuji dengan nilai yang benar-benar cocok.
- **[26-10-22 · core/agent.py]**: Pustaka skill pengguna terisi 10 playbook setiap startup dan test skill-capture gagal. → **Root Cause**: `install_playbooks(self.skill_manager)` dipanggil di `_init_cyber`, mencampur doktrin bawaan dengan skill yang dipelajari dan menulis ke `~/.aegisx/skills`. → **Invariant Rule**: data bawaan yang bersifat doktrin masuk ke prompt; disk pengguna hanya menerima apa yang dibuat atau diminta operator.
- **[26-10-22 · core/loop.py]**: Panggilan tool yang ditolak gate diulang terus sampai budget iterasi habis. → **Root Cause**: penolakan diperlakukan sebagai error biasa dan diserahkan ke `_recover_from_error`, yang meminta model memilih tool alternatif — jawabannya sering kali panggilan yang sama. → **Invariant Rule**: penolakan izin adalah keputusan kebijakan, bukan kegagalan; ia tidak masuk jalur recovery dan panggilan identik berikutnya dalam turn yang sama dijawab lokal tanpa menyentuh gate.
- **[26-10-22 · cli/main.py]**: Seluruh CLI crash saat start (`AttributeError: module 'typer' has no attribute 'ParameterInfo'`) — bukan cuma opsi `--version` yang baru. → **Root Cause**: anotasi callback memakai `typer.ParameterInfo`, yang tidak diekspor di level atas Typer modern (hanya ada di `typer.models`); karena `from __future__ import annotations`, Typer mengevaluasi string anotasi itu saat membangun command. → **Invariant Rule**: jangan menebak nama internal library di anotasi; pakai bentuk yang dijamin stabil (nilai opsi saja, `typer.Context`, atau `click.Parameter`) dan buktikan CLI tetap bisa start dengan satu perintah nyata.
- **[26-10-22 · installer.sh]**: Installer rusak di luar GNU/Linux dan mengabaikan perminta pengguna: `sed -i` gagal di macOS/BSD, `rm -rf` berjalan tanpa penjaga, `--dir` diabaikan saat dijalankan dari checkout, dan uninstall selalu menghapus lokasi default. → **Root Cause**: skrip ditulis hanya untuk satu keluarga sistem dan mengabaikan lokasi instalasi eksplisit. → **Invariant Rule**: installer harus portabel (deteksi GNU vs BSD, `rm -rf` hanya lewat penjaga, lokasi target selalu dibaca dari wrapper), dan setiap opsi yang ditulis pengguna harus punya efek yang terlihat.
- **[26-10-22 · tests/test_streaming.py]**: `pytest` meninggalkan `login.html` di root repo dan file itu sempat ikut ter-commit. → **Root Cause**: test memanggil tool dengan path relatif, sehingga file ditulis ke working directory proses. → **Invariant Rule**: test yang menulis path relatif wajib `chdir` ke `tmp_path`; file apa pun yang belum ada di `HEAD` dan muncul setelah test adalah artefak, bukan bagian dari perubahan.
- **[26-10-22 · .githooks/pre-push]**: Guard pembawa rahasian membiarkan private key PEM lolos, dan tidak ada yang complained karena `grep` hanya menulis "unrecognized option" ke stderr lalu guard tetap keluar 0. → **Root Cause**: pola `-----BEGIN ... PRIVATE KEY-----` diawali tanda hubung, jadi `grep` memperlakukannya sebagai daftar opsi; pemeriksa itu mati tanpa pernah cocok, dan `|| true` menutupi kegagalannya. Selain itu `git diff origin/main..HEAD` dibiarkan kosong pada push pertama dari clone baru, sehingga tidak ada yang dipindai sama sekali. → **Invariant Rule**: pola regex yang dimulai `-` wajib dipisah dengan `--` sebelum diteruskan ke `grep`; sebuah guard yang gagal diam-diam lebih berbahaya dari guard yang tidak ada, jadi setiap polanya harus dibuktikan memblokir lewat test yang menjalankan hook sungguhan di repo sementara — dan salinan hook yang aktif (`core.hooksPath`) harus ikut diuji, bukan hanya salinan yang ada di repo.
